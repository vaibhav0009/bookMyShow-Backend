# BookMyShow Backend

This is a simple backend project for a movie ticket booking app like BookMyShow. I built it using Java and Spring Boot to practice backend development.

## What it does

- Add and view movies
- Book movie tickets
- Handle errors properly using custom exceptions
- Use DTOs to send clean data in API responses

## Tech Used

- Java
- Spring Boot
- Spring Data JPA
- MySQL

## How to Run

1. Clone this repo
   ```bash
   git clone https://github.com/your-username/bookmyshow-backend.git
   ```

2. Open the project in your IDE (like IntelliJ or Eclipse)

3. Update the database details in `application.properties`

4. Run the `BookMyShowApplication.java` file

5. App will start on:
   ```
   http://localhost:8080
   ```

## Learning Purpose

This project is made for learning Spring Boot and understanding how backend APIs work with a real-world example.
